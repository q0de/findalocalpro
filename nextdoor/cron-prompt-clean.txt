## WORKFLOW

### STEP 1: Tab Cleanup
1. browser action=tabs, profile=openclaw - list all tabs
2. browser action=close, profile=openclaw for any nextdoor.com tabs (clean state)

### STEP 2: Load Config Files
Read:
- ~/clawd/findalocalpro/nextdoor/templates.json - response templates with phone numbers
- ~/clawd/findalocalpro/nextdoor/scoring.json - lead scoring rules
- ~/clawd/findalocalpro/nextdoor/activity-log.json - previous activity for dedup

### STEP 3: Check Daily Caps
Count today's posts from activity-log.json:
- If service_posts >= 3: ONLY do community engagement
- If total_posts >= 6: STOP and report daily limit reached

### STEP 4: Navigate to Nextdoor
```
browser action=navigate, targetUrl=https://nextdoor.com/news_feed/, profile=openclaw, timeoutMs=60000
```

### STEP 5: Get Page Content
```
browser action=snapshot, profile=openclaw, limit=50
```

Parse for:
- **Service requests:** Look for keywords like leak, clog, plumber, electrician, furnace, AC, ants, mice, dishwasher, etc.
- **Community posts:** Crime alerts, local news, weather, recommendations

For each post, extract:
- Author name
- Neighborhood
- Post age (e.g., "3d", "5h")
- Reply count
- Full text
- Post URL (from the link ref)

### STEP 6: Score Service Leads
Use scoring.json rules:
- Base score by service type
- Freshness decay (older = lower score)
- Competition factor (more replies = lower score)
- Emergency multiplier (burst pipe, no heat, etc.)

Skip if:
- Score < 50
- Post age > 48 hours
- Replies > 15
- Already responded (check activity-log.json)

### STEP 7: Select & Respond
Priority:
1. Highest-scoring service lead (if under daily cap)
2. Community engagement (maintain 3:1 ratio)

For each selected post:
1. **Navigate to post:**
   ```
   browser action=navigate, targetUrl=POST_URL, profile=openclaw, timeoutMs=60000
   ```

2. **Get snapshot to find comment box:**
   ```
   browser action=snapshot, profile=openclaw, refs=role
   ```

3. **Find the comment textbox** - look for ref with "Add a comment" or textbox role

4. **Click the textbox:**
   ```
   browser action=act, profile=openclaw, request={"kind":"click","ref":"REF_ID","timeMs":3000}
   ```

5. **Type response:**
   ```
   browser action=act, profile=openclaw, request={"kind":"type","ref":"REF_ID","text":"YOUR_TEMPLATE_TEXT"}
   ```

6. **Find and click submit button** - look for button with "Post" or submit type

7. **Wait** 5-20 minutes (natural pacing) before next response
