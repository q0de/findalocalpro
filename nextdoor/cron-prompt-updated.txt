## ⚠️ CRITICAL: BROWSER WORKAROUND (March 2, 2026)
The browser tool's `snapshot` and `act` actions are currently broken due to an OpenClaw bug that routes them through the wrong browser profile. **USE THIS WORKAROUND:**

**WORKING:**
- `browser action=navigate` with `profile='openclaw'` — USE THIS to open pages
- `browser action=tabs` — USE THIS to manage tabs
- `browser action=close` — USE THIS to close tabs

**BROKEN (DO NOT USE):**
- `browser action=snapshot` — Returns extension relay error
- `browser action=act` — Returns extension relay error

**WORKAROUND FOR PAGE CONTENT:**
After navigating, use direct CDP (Chrome DevTools Protocol) via exec:

```bash
# Get page text via CDP
curl -s "http://127.0.0.1:18800/json/list" | python3 -c "
import json, sys, asyncio, websockets

async def get_text():
    # Find the Nextdoor tab
    tabs = json.load(sys.stdin)
    target = None
    for t in tabs:
        if 'nextdoor' in t.get('url', ''):
            target = t['id']
            break
    if not target:
        print('No Nextdoor tab found')
        return
    
    # Connect and get content
    async with websockets.connect(f'ws://127.0.0.1:18800/devtools/page/{target}') as ws:
        await ws.send(json.dumps({
            'id': 1,
            'method': 'Runtime.evaluate',
            'params': {'expression': 'document.body.innerText', 'returnByValue': True}
        }))
        resp = json.loads(await ws.recv())
        print(resp['result']['result']['value'][:15000])

asyncio.run(get_text())
"
```

**WORKAROUND FOR CLICKING/TYPING:**
Use CDP Runtime.evaluate with JavaScript:

```bash
# Click an element
curl -s "http://127.0.0.1:18800/json/list" | python3 -c "
import json, sys, asyncio, websockets

async def click():
    # ...get target_id...
    async with websockets.connect(f'ws://127.0.0.1:18800/devtools/page/{target_id}') as ws:
        js = \"document.querySelector('button[type=submit]').click()\"
        await ws.send(json.dumps({
            'id': 1, 'method': 'Runtime.evaluate',
            'params': {'expression': js, 'returnByValue': True}
        }))
asyncio.run(click())
"
```
