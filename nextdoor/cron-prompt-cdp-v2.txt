   Match IMAGE_FILE to the service vertical (see table above).

6. **Post response with image** using browser tools:
   a. Click the comment textbox to focus it:
      ```
      browser action=act, kind=click, ref=COMMENT_TEXTBOX_REF
      ```
   b. Type the comment text:
      ```
      browser action=act, kind=type, ref=COMMENT_TEXTBOX_REF, text="TEMPLATE_TEXT"
      ```
   c. Click "Add photo" button (look for button with text "Add photo"):
      ```
      browser action=act, kind=click, ref=ADD_PHOTO_REF
      ```
   d. Upload the staged image:

      ```
      browser action=upload, paths=["/tmp/openclaw/uploads/IMAGE_FILE.png"]
      ```
   e. Wait 2 seconds for upload to process, then submit the comment:
